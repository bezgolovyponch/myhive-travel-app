# i18n Backend Implementation Plan (Plan 1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend half of multi-language support — store/resolve content translations (DE/ES/FR/CS) with EN fallback, DeepL machine-translation pipeline with manual-override protection, admin translation API + backfill, localized customer emails, hreflang sitemap. Fully backward compatible: without `lang` nothing changes.

**Architecture:** One generic `content_translations` table (entity_type, entity_id, locale, field → value, source MACHINE|MANUAL). Public endpoints take optional `?lang=`; a `CatalogLocalizer` overlays translations onto existing DTOs after mapping (batch query, no N+1). Admin saves queue async DeepL translation; MANUAL rows are never overwritten. Emails render with `Context(locale)` + `MessageSource` bundles keyed off a new `locale` column on Booking/TripLead/VoteSession.

**Tech Stack:** Spring Boot 4.0 / Java 25, Hibernate `ddl-auto=update` (prod) + `create-drop` (dev/test H2), `RestClient` for DeepL, Thymeleaf `SpringTemplateEngine` + `ResourceBundleMessageSource`, JUnit 5 + Mockito + AssertJ + MockMvc.

**Spec:** `docs/superpowers/specs/2026-08-04-i18n-multilanguage-design.md`

## Global Constraints

- Locales: `en` (base, implicit) + `de`, `es`, `fr`, `cs`. Invalid/absent `lang` → English behavior, byte-identical to today.
- Translatable fields: Activity(`name`,`description`,`includes`), Destination(`name`,`description`), Category(`name`), Package(`name`,`description`,`includes`), BlogPost(`title`,`excerpt`,`content`), QuizQuestion(`prompt`), QuizAnswer(`label`). **`Activity.duration` is an `Integer` — NOT translatable** (spec listed it in error; skip it).
- **No Flyway migration in this plan.** Repo convention (CLAUDE.md): Flyway is only for DDL that `ddl-auto=update` cannot do. A new table and new nullable columns are created by Hibernate `update` in prod automatically (precedent: `featured_weight`, `vote_mode`).
- Kill switch: `app.i18n.machine-translation-enabled=${MACHINE_TRANSLATION_ENABLED:false}` — off means saves succeed and no DeepL calls happen.
- DeepL API Free: `https://api-free.deepl.com/v2/translate`, header `Authorization: DeepL-Auth-Key <key>`, body `{"text":[...], "source_lang":"EN", "target_lang":"DE"}`, response `{"translations":[{"text":"..."}]}`. Target codes: `DE`, `ES`, `FR`, `CS`.
- Code style: Google Java Style, no wildcard imports, explicit imports, `@Override` always, Lombok idioms as in neighboring classes. Tests: AssertJ, `method_condition_expectedOutcome` naming, `expected`-prefixed variables shared between arrange and assert.
- Every `@Value` property you introduce MUST get a safe default in `src/main/resources/application.properties` AND be mirrored in `src/test/resources/application.properties` (it shadows main on the test classpath) — otherwise every `@SpringBootTest` fails to start.
- All commands run from `myhive-backend/`. Boot 4 gotchas: `@AutoConfigureMockMvc` import is `org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc`; mock beans via `@TestConfiguration` + `@Bean @Primary mock(...)` (NOT `@MockBean`).

```java
package com.myhive.backend.util;

import java.util.List;
import java.util.Locale;

/** Supported UI/content locales. English is the base language and never has translation rows. */
public final class Locales {

    public static final String DEFAULT_LOCALE = "en";

    public static final List<String> SUPPORTED = List.of("de", "es", "fr", "cs");

    private Locales() {
    }

    /**
     * Returns the lowercase locale code when it is a supported translation target,
     * otherwise {@code null} ("serve English, skip the lookup").
     */
    public static String normalize(String lang) {
        if (lang == null || lang.isBlank()) {
            return null;
        }
        String lower = lang.toLowerCase(Locale.ROOT);
        return SUPPORTED.contains(lower) ? lower : null;
    }

    /** Maps a stored locale code (nullable) to a java.util.Locale, defaulting to English. */
    public static Locale toLocale(String stored) {
        String normalized = normalize(stored);
        return normalized == null ? Locale.ENGLISH : Locale.forLanguageTag(normalized);
    }
}
```

`service/i18n/ContentTranslationService.java`:
```java
package com.myhive.backend.service.i18n;

import com.myhive.backend.entity.ContentTranslation;
import com.myhive.backend.model.ContentEntityType;
import com.myhive.backend.model.TranslationSource;
import com.myhive.backend.repository.ContentTranslationRepository;
import com.myhive.backend.util.Locales;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.ArrayList;
import java.util.Collection;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.UUID;

/**
 * Reads and writes rows of the generic content_translations table.
 * MANUAL rows are admin-authored and shielded from the machine pipeline.
 */
@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class ContentTranslationService {

    private final ContentTranslationRepository repository;

    /** Batch lookup for list endpoints: entityId -> (field -> translated value). */
    public Map<UUID, Map<String, String>> resolveAll(
            ContentEntityType type, Collection<UUID> ids, String locale) {
        String normalized = Locales.normalize(locale);
        if (normalized == null || ids.isEmpty()) {
            return Map.of();
        }
        Map<UUID, Map<String, String>> result = new HashMap<>();
        for (ContentTranslation t : repository.findByEntityTypeAndLocaleAndEntityIdIn(type, normalized, ids)) {
            result.computeIfAbsent(t.getEntityId(), k -> new HashMap<>()).put(t.getField(), t.getValue());
        }
        return result;
    }

    public Map<String, String> resolve(ContentEntityType type, UUID id, String locale) {
        return resolveAll(type, List.of(id), locale).getOrDefault(id, Map.of());
    }

    /** Machine upsert: creates or updates MACHINE rows; never touches MANUAL rows. */
    @Transactional
    public void upsertMachine(ContentEntityType type, UUID id, String locale, Map<String, String> fields) {
        writeRows(type, id, locale, fields, TranslationSource.MACHINE, true);
    }

    /** Admin save: creates or overwrites rows as MANUAL; a blank value deletes the row. */
    @Transactional
    public void saveManual(ContentEntityType type, UUID id, String locale, Map<String, String> fields) {
        writeRows(type, id, locale, fields, TranslationSource.MANUAL, false);
    }

    @Transactional
    public void deleteAllFor(ContentEntityType type, UUID id) {
        repository.deleteByEntityTypeAndEntityId(type, id);
    }

    @Transactional
    public void deleteLocale(ContentEntityType type, UUID id, String locale) {
        String normalized = Locales.normalize(locale);
        if (normalized != null) {
            repository.deleteByEntityTypeAndEntityIdAndLocale(type, id, normalized);
        }
    }

    public List<ContentTranslation> getAllForEntity(ContentEntityType type, UUID id) {
        return repository.findByEntityTypeAndEntityId(type, id);
    }

    public boolean hasAnyTranslations(ContentEntityType type, UUID id) {
        return repository.existsByEntityTypeAndEntityId(type, id);
    }

    private void writeRows(ContentEntityType type, UUID id, String locale,
                           Map<String, String> fields, TranslationSource source, boolean protectManual) {
        String normalized = Locales.normalize(locale);
        if (normalized == null) {
            return;
        }
        Map<String, ContentTranslation> existing = new HashMap<>();
        for (ContentTranslation t : repository.findByEntityTypeAndEntityIdAndLocale(type, id, normalized)) {
            existing.put(t.getField(), t);
        }
        List<ContentTranslation> toSave = new ArrayList<>();
        for (Map.Entry<String, String> entry : fields.entrySet()) {
            String field = entry.getKey();
            String value = entry.getValue();
            ContentTranslation current = existing.get(field);
            if (current != null && protectManual && current.getSource() == TranslationSource.MANUAL) {
                continue;
            }
            if (value == null || value.isBlank()) {
                if (current != null && !protectManual) {
                    repository.delete(current);
                }
                continue;
            }
            if (current != null) {
                current.setValue(value);
                current.setSource(source);
                toSave.add(current);
            } else {
                ContentTranslation created = new ContentTranslation();
                created.setEntityType(type);
                created.setEntityId(id);
                created.setLocale(normalized);
                created.setField(field);
                created.setValue(value);
                created.setSource(source);
                toSave.add(created);
            }
        }
        if (!toSave.isEmpty()) {
            repository.saveAll(toSave);
        }
    }
}
```

```java
package com.myhive.backend.service.i18n;

import com.myhive.backend.dto.ActivityDTO;
import com.myhive.backend.dto.BlogPostDTO;
import com.myhive.backend.dto.CategoryDTO;
import com.myhive.backend.dto.DestinationDTO;
import com.myhive.backend.dto.PackageActivityRefDTO;
import com.myhive.backend.dto.PackageDTO;
import com.myhive.backend.dto.PublicQuizAnswerDTO;
import com.myhive.backend.dto.PublicQuizDTO;
import com.myhive.backend.dto.PublicQuizQuestionDTO;
import com.myhive.backend.model.ContentEntityType;
import com.myhive.backend.util.Locales;
import lombok.RequiredArgsConstructor;
import org.springframework.data.domain.Page;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.Map;
import java.util.UUID;
import java.util.function.Function;

/**
 * Overlays content translations onto catalog DTOs after mapping. With a null or
 * unsupported lang every method is a strict no-op, so English responses are
 * byte-identical to the pre-i18n behavior.
 */
@Service
@RequiredArgsConstructor
public class CatalogLocalizer {

    private final ContentTranslationService translations;

    public List<ActivityDTO> activities(List<ActivityDTO> dtos, String lang) {
        if (Locales.normalize(lang) == null || dtos.isEmpty()) {
            return dtos;
        }
        Map<UUID, Map<String, String>> byId = translations.resolveAll(
                ContentEntityType.ACTIVITY, dtos.stream().map(ActivityDTO::getId).toList(), lang);
        for (ActivityDTO dto : dtos) {
            Map<String, String> t = byId.getOrDefault(dto.getId(), Map.of());
            dto.setName(t.getOrDefault("name", dto.getName()));
            dto.setDescription(t.getOrDefault("description", dto.getDescription()));
            dto.setIncludes(t.getOrDefault("includes", dto.getIncludes()));
            localizeCategories(dto.getCategories(), lang);
        }
        return dtos;
    }

    public ActivityDTO activity(ActivityDTO dto, String lang) {
        activities(List.of(dto), lang);
        return dto;
    }

    public Page<ActivityDTO> activities(Page<ActivityDTO> page, String lang) {
        activities(page.getContent(), lang);
        return page;
    }

    public List<DestinationDTO> destinations(List<DestinationDTO> dtos, String lang) {
        if (Locales.normalize(lang) == null || dtos.isEmpty()) {
            return dtos;
        }
        Map<UUID, Map<String, String>> byId = translations.resolveAll(
                ContentEntityType.DESTINATION, dtos.stream().map(DestinationDTO::getId).toList(), lang);
        for (DestinationDTO dto : dtos) {
            Map<String, String> t = byId.getOrDefault(dto.getId(), Map.of());
            dto.setName(t.getOrDefault("name", dto.getName()));
            dto.setDescription(t.getOrDefault("description", dto.getDescription()));
            localizeCategories(dto.getAssignedCategories(), lang);
        }
        return dtos;
    }

    public DestinationDTO destination(DestinationDTO dto, String lang) {
        destinations(List.of(dto), lang);
        return dto;
    }

    public List<CategoryDTO> categories(List<CategoryDTO> dtos, String lang) {
        localizeCategories(dtos, lang);
        return dtos;
    }

    public CategoryDTO category(CategoryDTO dto, String lang) {
        localizeCategories(List.of(dto), lang);
        return dto;
    }

    public List<PackageDTO> packages(List<PackageDTO> dtos, String lang) {
        if (Locales.normalize(lang) == null || dtos.isEmpty()) {
            return dtos;
        }
        Map<UUID, Map<String, String>> byId = translations.resolveAll(
                ContentEntityType.PACKAGE, dtos.stream().map(PackageDTO::getId).toList(), lang);
        List<UUID> refActivityIds = dtos.stream()
                .flatMap(p -> p.getActivities().stream())
                .map(PackageActivityRefDTO::getActivityId)
                .toList();
        Map<UUID, Map<String, String>> activityNames = translations.resolveAll(
                ContentEntityType.ACTIVITY, refActivityIds, lang);
        for (PackageDTO dto : dtos) {
            Map<String, String> t = byId.getOrDefault(dto.getId(), Map.of());
            dto.setName(t.getOrDefault("name", dto.getName()));
            dto.setDescription(t.getOrDefault("description", dto.getDescription()));
            dto.setIncludes(t.getOrDefault("includes", dto.getIncludes()));
            for (PackageActivityRefDTO ref : dto.getActivities()) {
                Map<String, String> at = activityNames.getOrDefault(ref.getActivityId(), Map.of());
                ref.setName(at.getOrDefault("name", ref.getName()));
            }
            localizeCategories(dto.getCategories(), lang);
        }
        return dtos;
    }

    public PackageDTO pkg(PackageDTO dto, String lang) {
        packages(List.of(dto), lang);
        return dto;
    }

    public List<BlogPostDTO> blogPosts(List<BlogPostDTO> dtos, String lang) {
        if (Locales.normalize(lang) == null || dtos.isEmpty()) {
            return dtos;
        }
        Map<UUID, Map<String, String>> byId = translations.resolveAll(
                ContentEntityType.BLOG_POST, dtos.stream().map(BlogPostDTO::getId).toList(), lang);
        for (BlogPostDTO dto : dtos) {
            Map<String, String> t = byId.getOrDefault(dto.getId(), Map.of());
            dto.setTitle(t.getOrDefault("title", dto.getTitle()));
            dto.setExcerpt(t.getOrDefault("excerpt", dto.getExcerpt()));
            dto.setContent(t.getOrDefault("content", dto.getContent()));
        }
        return dtos;
    }

    public BlogPostDTO blogPost(BlogPostDTO dto, String lang) {
        blogPosts(List.of(dto), lang);
        return dto;
    }

    public PublicQuizDTO quiz(PublicQuizDTO quiz, String lang) {
        if (Locales.normalize(lang) == null || quiz.getQuestions() == null || quiz.getQuestions().isEmpty()) {
            return quiz;
        }
        Map<UUID, Map<String, String>> prompts = translations.resolveAll(
                ContentEntityType.QUIZ_QUESTION,
                quiz.getQuestions().stream().map(PublicQuizQuestionDTO::getId).toList(), lang);
        Map<UUID, Map<String, String>> labels = translations.resolveAll(
                ContentEntityType.QUIZ_ANSWER,
                quiz.getQuestions().stream()
                        .flatMap(q -> q.getAnswers().stream())
                        .map(PublicQuizAnswerDTO::getId)
                        .toList(), lang);
        for (PublicQuizQuestionDTO question : quiz.getQuestions()) {
            question.setPrompt(prompts.getOrDefault(question.getId(), Map.of())
                    .getOrDefault("prompt", question.getPrompt()));
            for (PublicQuizAnswerDTO answer : question.getAnswers()) {
                answer.setLabel(labels.getOrDefault(answer.getId(), Map.of())
                        .getOrDefault("label", answer.getLabel()));
            }
        }
        return quiz;
    }

    private void localizeCategories(List<CategoryDTO> dtos, String lang) {
        if (Locales.normalize(lang) == null || dtos == null || dtos.isEmpty()) {
            return;
        }
        Map<UUID, Map<String, String>> byId = translations.resolveAll(
                ContentEntityType.CATEGORY, dtos.stream().map(CategoryDTO::getId).toList(), lang);
        for (CategoryDTO dto : dtos) {
            dto.setName(byId.getOrDefault(dto.getId(), Map.of()).getOrDefault("name", dto.getName()));
        }
    }
}
```

```java
package com.myhive.backend.service.i18n;

import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestClient;

import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Optional;

/**
 * Thin DeepL REST client. Failure never propagates: any error yields Optional.empty()
 * so admin saves are never blocked by the translation provider.
 */
@Service
@Slf4j
public class DeepLTranslator {

    private final String apiKey;
    private final boolean enabled;
    private final RestClient restClient;

    public DeepLTranslator(
            @Value("${deepl.api-key:}") String apiKey,
            @Value("${deepl.api-url}") String apiUrl,
            @Value("${app.i18n.machine-translation-enabled:false}") boolean enabled,
            RestClient.Builder restClientBuilder) {
        this.apiKey = apiKey;
        this.enabled = enabled;
        this.restClient = restClientBuilder.baseUrl(apiUrl).build();
    }

    public boolean isEnabled() {
        return enabled && apiKey != null && !apiKey.isBlank();
    }

    /** Translates texts from English to the given supported locale, preserving order. */
    public Optional<List<String>> translate(List<String> texts, String targetLocale) {
        if (!isEnabled()) {
            return Optional.empty();
        }
        if (texts.isEmpty()) {
            return Optional.of(List.of());
        }
        try {
            Map<String, Object> body = Map.of(
                    "text", texts,
                    "source_lang", "EN",
                    "target_lang", targetLocale.toUpperCase(Locale.ROOT)
            );
            DeepLResponse response = restClient.post()
                    .header("Authorization", "DeepL-Auth-Key " + apiKey)
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(body)
                    .retrieve()
                    .body(DeepLResponse.class);
            if (response == null || response.translations() == null
                    || response.translations().size() != texts.size()) {
                log.warn("DeepL returned unexpected payload for target {}", targetLocale);
                return Optional.empty();
            }
            return Optional.of(response.translations().stream().map(DeepLTranslation::text).toList());
        } catch (Exception e) {
            log.error("DeepL translation to {} failed: {}", targetLocale, e.getMessage(), e);
            return Optional.empty();
        }
    }

    private record DeepLResponse(List<DeepLTranslation> translations) {
    }

    private record DeepLTranslation(String text) {
    }
}
```

```java
package com.myhive.backend.service.i18n;

import com.myhive.backend.model.ContentEntityType;
import com.myhive.backend.util.Locales;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.UUID;

/**
 * Fans English source fields out to all supported locales via DeepL and stores
 * the results as MACHINE rows. Fire-and-forget: failures are logged, never thrown.
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class TranslationPipeline {

    private final DeepLTranslator deepL;
    private final ContentTranslationService translations;

    @Async("translationTaskExecutor")
    public void translateAsync(ContentEntityType type, UUID entityId, Map<String, String> englishFields) {
        try {
            translateNow(type, entityId, englishFields);
        } catch (Exception e) {
            // Fire-and-forget off the request thread: nothing to surface to the caller.
            log.error("Machine translation for {} {} failed: {}", type, entityId, e.getMessage(), e);
        }
    }

    public void translateNow(ContentEntityType type, UUID entityId, Map<String, String> englishFields) {
        if (!deepL.isEnabled()) {
            return;
        }
        Map<String, String> nonBlank = new LinkedHashMap<>();
        englishFields.forEach((field, value) -> {
            if (value != null && !value.isBlank()) {
                nonBlank.put(field, value);
            }
        });
        if (nonBlank.isEmpty()) {
            return;
        }
        List<String> fieldNames = new ArrayList<>(nonBlank.keySet());
        List<String> sourceTexts = fieldNames.stream().map(nonBlank::get).toList();
        for (String locale : Locales.SUPPORTED) {
            Optional<List<String>> translated = deepL.translate(sourceTexts, locale);
            if (translated.isEmpty()) {
                log.warn("Skipping locale {} for {} {}: translation unavailable", locale, type, entityId);
                continue;
            }
            Map<String, String> byField = new LinkedHashMap<>();
            for (int i = 0; i < fieldNames.size(); i++) {
                byField.put(fieldNames.get(i), translated.get().get(i));
            }
            translations.upsertMachine(type, entityId, locale, byField);
        }
    }
}
```

```java
import com.myhive.backend.entity.Activity;

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.LinkedHashMap;
import java.util.Map;

import java.util.function.Supplier;

/**
 * One-shot idempotent backfill: machine-translates every entity that has no
 * translation rows yet. Batched via ?limit so a single HTTP request stays short.
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class TranslationBackfillService {

    private final ActivityRepository activityRepository;
    private final DestinationRepository destinationRepository;
    private final CategoryRepository categoryRepository;
    private final PackageRepository packageRepository;
    private final BlogPostRepository blogPostRepository;
    private final QuizQuestionRepository quizQuestionRepository;
    private final ContentTranslationService translations;
    private final TranslationPipeline pipeline;
    private final DeepLTranslator deepL;

    @Transactional
    public int backfill(int limit) {
        if (!deepL.isEnabled()) {
            return 0;
        }
        int processed = 0;
        processed += backfillType(limit - processed, ContentEntityType.ACTIVITY,
                () -> activityRepository.findAll().stream()
                        .map(a -> new Item(a.getId(), activityFields(a))).toList());
        processed += backfillType(limit - processed, ContentEntityType.DESTINATION,
                () -> destinationRepository.findAll().stream()
                        .map(d -> new Item(d.getId(), destinationFields(d))).toList());
        processed += backfillType(limit - processed, ContentEntityType.CATEGORY,
                () -> categoryRepository.findAll().stream()
                        .map(c -> new Item(c.getId(), Map.of("name", nullSafe(c.getName())))).toList());
        processed += backfillType(limit - processed, ContentEntityType.PACKAGE,
                () -> packageRepository.findAll().stream()
                        .map(p -> new Item(p.getId(), packageFields(p))).toList());
        processed += backfillType(limit - processed, ContentEntityType.BLOG_POST,
                () -> blogPostRepository.findAll().stream()
                        .map(b -> new Item(b.getId(), blogFields(b))).toList());
        processed += backfillType(limit - processed, ContentEntityType.QUIZ_QUESTION,
                () -> quizQuestionRepository.findAll().stream()
                        .map(q -> new Item(q.getId(), Map.of("prompt", nullSafe(q.getPrompt())))).toList());
        processed += backfillType(limit - processed, ContentEntityType.QUIZ_ANSWER,
                () -> quizQuestionRepository.findAll().stream()
                        .flatMap(q -> q.getAnswers().stream())
                        .map(a -> new Item(a.getId(), Map.of("label", nullSafe(a.getLabel())))).toList());
        return processed;
    }

    private record Item(UUID id, Map<String, String> fields) {
    }

    private int backfillType(int budget, ContentEntityType type, Supplier<java.util.List<Item>> loader) {
        if (budget <= 0) {
            return 0;
        }
        int done = 0;
        for (Item item : loader.get()) {
            if (done >= budget) {
                break;
            }
            if (translations.hasAnyTranslations(type, item.id())) {
                continue;
            }
            pipeline.translateNow(type, item.id(), item.fields());
            done++;
        }
        return done;
    }

    private static Map<String, String> activityFields(Activity a) {
        Map<String, String> m = new LinkedHashMap<>();
        m.put("name", a.getName());
        m.put("description", a.getDescription());
        m.put("includes", a.getIncludes());
        return m;
    }

    private static Map<String, String> destinationFields(Destination d) {
        Map<String, String> m = new LinkedHashMap<>();
        m.put("name", d.getName());
        m.put("description", d.getDescription());
        return m;
    }

    private static Map<String, String> packageFields(Package p) {
        Map<String, String> m = new LinkedHashMap<>();
        m.put("name", p.getName());
        m.put("description", p.getDescription());
        m.put("includes", p.getIncludes());
        return m;
    }

    private static Map<String, String> blogFields(BlogPost b) {
        Map<String, String> m = new LinkedHashMap<>();
        m.put("title", b.getTitle());
        m.put("excerpt", b.getExcerpt());
        m.put("content", b.getContent());
        return m;
    }

    private static String nullSafe(String value) {
        return value == null ? "" : value;
    }
}
```

```java
package com.myhive.backend.controller;

import com.myhive.backend.dto.BackfillResultDTO;
import com.myhive.backend.dto.TranslationEntryDTO;
import com.myhive.backend.entity.ContentTranslation;
import com.myhive.backend.model.ContentEntityType;
import com.myhive.backend.service.i18n.ContentTranslationService;
import com.myhive.backend.service.i18n.TranslationBackfillService;
import com.myhive.backend.service.i18n.TranslationPipeline;
import lombok.RequiredArgsConstructor;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.util.HashMap;
import java.util.Map;
import java.util.UUID;

@RestController
@RequestMapping("/admin/i18n")
@RequiredArgsConstructor
public class AdminI18nController {

    private final ContentTranslationService translations;
    private final TranslationPipeline pipeline;
    private final TranslationBackfillService backfillService;

    @GetMapping("/translations")
    public ResponseEntity<Map<String, Map<String, TranslationEntryDTO>>> getTranslations(
            @RequestParam ContentEntityType entityType,
            @RequestParam UUID entityId) {
        Map<String, Map<String, TranslationEntryDTO>> byLocale = new HashMap<>();
        for (ContentTranslation t : translations.getAllForEntity(entityType, entityId)) {
            byLocale.computeIfAbsent(t.getLocale(), k -> new HashMap<>())
                    .put(t.getField(), new TranslationEntryDTO(t.getValue(), t.getSource().name()));
        }
        return ResponseEntity.ok(byLocale);
    }

    @PutMapping("/translations/{entityType}/{entityId}/{locale}")
    public ResponseEntity<Void> saveTranslations(
            @PathVariable ContentEntityType entityType,
            @PathVariable UUID entityId,
            @PathVariable String locale,
            @RequestBody Map<String, String> fields) {
        translations.saveManual(entityType, entityId, locale, fields);
        return ResponseEntity.noContent().build();
    }

    @PostMapping("/translations/{entityType}/{entityId}/{locale}/retranslate")
    public ResponseEntity<Void> retranslate(
            @PathVariable ContentEntityType entityType,
            @PathVariable UUID entityId,
            @PathVariable String locale,
            @RequestBody(required = false) Map<String, String> englishFields) {
        translations.deleteLocale(entityType, entityId, locale);
        if (englishFields != null && !englishFields.isEmpty()) {
            pipeline.translateNow(entityType, entityId, englishFields);
        }
        return ResponseEntity.noContent().build();
    }

    @PostMapping("/backfill")
    public ResponseEntity<BackfillResultDTO> backfill(@RequestParam(defaultValue = "20") int limit) {
        int safeLimit = Math.min(Math.max(limit, 1), 100);
        int processed = backfillService.backfill(safeLimit);
        return ResponseEntity.ok(new BackfillResultDTO(processed, processed >= safeLimit));
    }
}
```

```java
private void appendUrl(StringBuilder xml, String path) {
    List<String> localePrefixes = new ArrayList<>();
    localePrefixes.add("");                                  // en, unprefixed
    for (String locale : Locales.SUPPORTED) {
        localePrefixes.add("/" + locale);
    }
    for (String prefix : localePrefixes) {
        xml.append("  <url><loc>").append(escapeXml(frontendUrl + prefix + path)).append("</loc>\n");
        xml.append("    <xhtml:link rel=\"alternate\" hreflang=\"en\" href=\"")
                .append(escapeXml(frontendUrl + path)).append("\"/>\n");
        for (String locale : Locales.SUPPORTED) {
            xml.append("    <xhtml:link rel=\"alternate\" hreflang=\"").append(locale).append("\" href=\"")
                    .append(escapeXml(frontendUrl + "/" + locale + path)).append("\"/>\n");
        }
        xml.append("    <xhtml:link rel=\"alternate\" hreflang=\"x-default\" href=\"")
                .append(escapeXml(frontendUrl + path)).append("\"/>\n");
        xml.append("  </url>\n");
    }
}
```
