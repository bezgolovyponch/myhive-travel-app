# UK stag-do aggregators: how they present their PRAGUE activity catalogues (2026)

Scope: StagWeb, Last Night of Freedom (LNOF), Chillisauce, Maximise, Pissup, Stag Republic, Red Seven (now Funktion Events). All pages were fetched **live on 2026-10-10**; nothing below comes from Wayback. Prices are quoted only where visible on the page. "pp" = per person. Where a fetch truncated a page, that is noted.

Two scope corrections up front:
- **Stag Republic does not sell Prague.** Its live domain is `stagrepublic.co.uk` (the `.com` did not resolve); its destinations are Budapest, Krakow and Riga only, and the footer still reads "© 2005-2019" — [Stag Republic homepage](https://www.stagrepublic.co.uk/).
- **Red Seven is now Funktion Events.** `redsevenleisure.co.uk/stag-weekends/prague/` 301-redirects to [funktionevents.co.uk/stag-do/czech-republic/prague](https://www.funktionevents.co.uk/stag-do/czech-republic/prague). Funktion is the only one of the six that prints a per-activity price in list and detail view.

## Key Question 1 — Per-site Prague catalogue (activities, prices, durations, minimums) and list/card/detail layout

### Takeaway
Five of six live competitors hide activity prices entirely (price appears only on packages or after an enquiry/"see prices" step); only Funktion Events shows a bold price on every card and detail page. Card layouts split into two families: "bullet cards" (StagWeb, LNOF, Funktion: image + name + 3-6 inclusion bullets + CTA) and "text cards" (Chillisauce, Pissup: image + name + one-line description + review count/CTA); Maximise is an outlier with title + emoji badge only. Detail pages converge on the same skeleton: Includes list -> short description -> structured facts (duration / min-max people / dress / transfer) -> reviews -> related items.
