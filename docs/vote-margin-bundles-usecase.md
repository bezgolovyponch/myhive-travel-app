# Юзкейс: «Готовые бандлы после группового голосования»

> Документ для обсуждения с командой. Продуктовое описание, без технических деталей.
> Дата: 2026-06-04

## Зачем

Сейчас после голосования группа видит свой результат и плоский список рекомендаций — но
из списка отдельных активностей человеку тяжело собрать поездку, а мы не управляем тем,
что он добавит. Хотим:

1. Упростить пользователю финальный выбор.
2. Аккуратно подвести его к активностям, выгодным нам по марже.

## Сценарий

1. Все участники проголосовали, организатор закрывает сессию.
2. На странице результата группа видит, как и раньше: «Выбор группы» (что победило),
   бюджет и обычные рекомендации — **этот путь остаётся без изменений**.
3. **Новое:** появляется секция «Подобрали для вас» с **3–4 готовыми бандлами**.
4. Пользователь кликает на понравившийся бандл → он целиком загружается в Trip Builder →
   дальше обычное оформление заказа.

## Что такое бандл

Каждый бандл — это **готовая поездка одним кликом**: то, что выбрала группа в голосовании,
**плюс** несколько дополнительных активностей, которые мы добавляем сами.

- **Ядро** во всех бандлах одинаковое — победители голосования (честный выбор группы
  сохраняется).
- **Различаются бандлы темой.** Берём главные интересы группы из квиза (например
  «Ночная жизнь», «Приключения», «Культура и еда») — каждая тема даёт отдельный бандл.
- **Добор внутри темы — по выгодности для нас.** В рамках темы система докидывает самые
  маржинальные для нас активности, **пока хватает остатка бюджета группы**. То есть
  пользователь выбирает по вкусу (тема), а мы внутри темы продвигаем выгодное.

## Что видит пользователь

3–4 карточки. На каждой:

- название темы,
- список активностей внутри (выбор группы + наши дополнения),
- итоговая цена бандла.

Цена полная, без скидок. Один клик — и весь набор уже в корзине, осталось оформить.

## Поведение в краях

- Если по теме нечего выгодного добавить — бандл по ней просто не показываем.
- Активности, которые группа уже отклонила в голосовании, повторно не подсовываем.
- Если у группы не было бюджета — добор ограничиваем разумным числом, а не суммой.
- Если группа вообще ни на чём не сошлась — бандл соберётся из тематических рекомендаций
  «с нуля».

## Ценность для бизнеса

- **Выше конверсия:** «собрать поездку» превращается в «выбрать один из 3–4 готовых
  вариантов».
- **Выше маржа:** мы управляем тем, чем наполняется поездка, оставаясь в рамках бюджета
  группы.
- **Доверие сохраняется:** результат голосования никуда не девается, бандлы — это
  надстройка-предложение, а не подмена выбора.
